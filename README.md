# Ranking public job vacancies in Peru with sentence embeddings

This repository holds the source code and the training configuration of the model described in the paper *Reaching a Lexical Baseline with Sentence Embeddings: Ranking Public Job Vacancies in Peru*.

The encoder is `paraphrase-multilingual-MiniLM-L12-v2`, a public sentence transformer. It was not created for this work. The contribution is the fine-tune on labeled Peruvian pairs and the comparison against a lexical baseline.

## What is here

- `src/` and `scripts/`: the matching pipeline and the experiments E0 to E5. `src/common.py` holds the hash gate, the seed and the run log.
- `config.yaml` and `requirements.txt`: the frozen training configuration (B2, cosine-similarity loss, two epochs, seed 42).
- `PROTOCOLO_EXPERIMENTAL.md`: the frozen experimental protocol. `DECISIONES.md` records any deviation.
- `data/raw/`: the six canonical CSV files. No personal data.
- `src/resources/stopwords_es.txt`: the Spanish stopword list used by the lexical baseline. It is stored here so a run does not download it.
- `tests/test_metrics.py`: the metric checks that E0 must pass before any experiment runs.
- `results/`: the aggregate metrics of each run.
- `docker-compose.yml`: a demo of the already trained model. It is not the way to reproduce the experiments.

The fine-tuned weights are not in this repository. They are regenerated by `scripts/e3_finetune.py`, and they are already inside the API image used by the demo.

## Reproduce the comparison

```bash
python -m venv .venv
```

Activate it, then:

```bash
pip install -r requirements.txt
python scripts/setup_assets.py
python scripts/e0_prep.py
python scripts/e1_bm25.py
python scripts/e2_zeroshot.py
python scripts/e3_finetune.py
python scripts/e4_final.py
python scripts/e5_efficiency.py
```

`setup_assets.py` writes the stopword list and downloads the base encoder from Hugging Face, recording its exact revision. E0 checks the six file hashes and the metric tests. If a check fails, it stops. The numbers in `results/` match the table and the figure of the paper.

## Try the trained model

This starts the database, the API and a small web page. It does not rerun the experiments.

```bash
docker compose up
```

Open http://localhost:5173. The first start downloads the images and loads the vacancy catalog. No GPU is required.

## Data

The vacancy listings come from the Peruvian Ministry of Labour, public data under the Open Data Commons Attribution license, downloaded from the National Open Data Platform (https://www.datosabiertos.gob.pe/).
